Claude Code v2.1.302：待機中の会話の圧縮を切り替え可能に、単体版Claude Designの終了予告も表示

30秒でわかる

  • Claude Code（ターミナルで動くAIの開発支援ツール）がv2.1.302に更新
  • しばらく操作しないときに会話を自動で圧縮する機能を、/configでオン・オフできるようになった
  • 単体版のClaude Design（claude.ai/design）が2026年12月14日までに終了するという案内が、関連コマンドに表示されるようになった

何が変わった

Claude Codeのv2.1.302では、設定画面（/config）に「Idle compaction」の項目が加わりました。Idle compactionは、しばらく操作がないときに会話を要約して短くする（圧縮する）機能です。この項目でオフにも、オンに戻すこともできます。圧縮後に出る案内にも、オフにする方法が書かれるようになりました。また、Claude Designと連携する/design-syncと/design-loginのコマンドに、単体版のClaude Designが2026年12月14日までに終了するという案内が出ます。修正では、WindowsでexFATやFAT32のドライブにあるプロジェクトだと、ファイルの書き込みが毎回拒否されたり確認を求められたりする問題が直りました。プラグインを多く入れているときの起動も速くなり、とくにWindowsで効果が大きいとされています。ほかに、128MBを超える画像は読み込みを断るようになるなど、細かな修正が多数入っています。

誰に関係する

Claude Codeを使っている人、とくにWindowsでUSBメモリや外付けドライブ（exFAT・FAT32）上で作業している人や、Claude Designを使っている人に関係します。
