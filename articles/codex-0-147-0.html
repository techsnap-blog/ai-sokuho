OpenAI Codex CLI 0.147.0：拡張機能の強化と自動承認を追加、「全おまかせ実行」は廃止

30秒でわかる

  • 拡張機能（プラグイン）を、ネット上のカタログから探して入れられるように。自分のPC・個人・チーム・ネット上をまたいで検索できる
  • AIの操作を毎回手で承認しなくても、自動でチェックして進める `--approve-for-me` を追加
  • 昔からあった `codex exec --full-auto`（全部おまかせ実行）は廃止。これを使っていた自動化の設定は書き換えが必要

何が変わった

今回の目玉は拡張機能（プラグイン）まわりです。自分のPCの中だけでなく、個人・チーム・ネット上のカタログまでまとめて探して入れられるようになりました。作業を進めるときの「承認」も、`--approve-for-me` を付ければ毎回手で押さなくても自動でチェックして進められます。ほかに、AIが外部ツールとやり取りする共通ルール（MCP）の新版に対応したほか、Cursorという別のツールで作った設定を取り込んで、ClaudeやCursorとの会話を重複なく同期する機能、Amazon Bedrock（AWSのAI基盤）向けの改善も入りました。不具合の修正も多く、画面に出すコマンドや履歴からパスワード類を隠す、日本語や絵文字の表示崩れ、Windowsでの動作不良などが直っています。一方で、以前から「非推奨（いずれ廃止）」とされていた `codex exec --full-auto`（確認なしで全部おまかせ実行するオプション）は削除されました。これを自動化スクリプトで使っている場合は、更新前に別の書き方へ置き換える必要があります。料金への影響は公式には書かれていません。

誰に関係する

Codex（コーディング支援のCLIツール）を使う人に広く関係します。とくに拡張機能を使う人、Cursorや Claudeと一緒に使っている人、AWSのBedrockで動かしている人、日本語の表示崩れに困っていた人にはうれしい更新です。`codex exec --full-auto` を自動化の中で使っているなら、更新前に置き換えを確認してください。
