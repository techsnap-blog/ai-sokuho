Claude Code v2.1.223：セキュリティ修正が中心、/review が /code-review に統合

30秒でわかる

  • 悪意ある操作を防ぐためのセキュリティ修正が中心。承認画面をだましてコマンドの一部を隠す手口などをふさいだ
  • コマンド `/review` が `/code-review` に統合（今の変更点やプルリクエストをレビューする機能）
  • クラウドで動かしていた作業を手元のPCで続ける `/teleport` のヒント表示を追加

何が変わった

今回はセキュリティと不具合の修正がメインです。とくに、承認をうながす画面をだまして、実行するコマンドの一部を隠せてしまう問題（タブや目に見えない文字を使う手口）や、本来なら制限された領域（サンドボックス）の外でコードを動かせてしまう問題が直りました。使い勝手の面では、コマンドの `/review` が `/code-review`（今の変更やプルリクエストをレビューする機能）に一本化され、クラウド上のセッションを手元のPCで続けるための `/teleport` の案内も出るようになりました。ほかにも、組織の管理設定まわりの調整や細かなバグ修正が多数入っています。料金への影響は記載されていません。

誰に関係する

Claude Codeを使っている開発者は、セキュリティ修正のため更新しておくのがおすすめです。とくに会社などチームで使っている場合は、管理設定の挙動修正も含まれます。`/review` を使っていた人は、今後 `/code-review` に読み替えればOKです。
