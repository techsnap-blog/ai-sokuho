Claude Code v2.1.224：自前のPCで動かす機能とAI同士のメッセージ連携を追加

30秒でわかる

  • 自分のパソコンやサーバーを、Claude Codeが動く「作業場所」にできる機能を追加（＝会社のマシン上で動かせる。Team・Enterpriseプラン向け）
  • 別々の場所で動いているClaude Code同士が、メッセージをやり取りできるように（Mac・Linux）
  • 拡張機能（プラグイン）を、開発者向けツール（Git・NPM）なしで、ネット上のZIPファイルからそのまま入れられるように

何が変わった

今回いちばん大きいのは、自分のパソコンやサーバーをClaude Codeの実行場所にできる機能（セルフホスト＝自前環境で動かすこと）です。Web・スマホ・デスクトップのどこから使っても、指定した自分のマシン上で処理を動かせます（Team・Enterpriseプランが対象）。あわせて、別々のマシンで動いているClaude Code同士がメッセージをやり取りできるようになりました（Mac・Linux）。拡張機能（プラグイン）の入れ方も増え、GitやNPMといった開発者向けツールを使わずに、ネット上のZIPファイルからそのまま追加できます。ほかに細かい不具合の修正も多く、たとえば名前の長いフォルダで別プロジェクトの作業履歴が混ざってしまう問題や、メッセージ送信が失敗しても「送信済み」と表示されていた問題などが直りました。料金への影響は公式には書かれていません。

誰に関係する

自分のパソコンやサーバーでClaude Codeを動かしたいチーム・企業の利用者、複数のパソコンやウィンドウを並行して使う人、拡張機能を配ったり管理したりする人に関係します。個人で1台だけで使っているなら、今回は主に不具合の修正が恩恵になります。
