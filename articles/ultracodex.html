Claude Code向けのワークフローを書き換えずCodex CLIで動かす「ultracodex」

30秒でわかる

  • Claude Code用に書いた作業手順を、書き換えずにCodex CLIやOpenCodeでも実行できる（裏側の違いをツールが吸収する）
  • AIを関数のように呼び出して手順を書け、「Claudeが手順を書き、Codexが実行し、Claudeが検証する」など複数AIの分担を1本のスクリプトに組める
  • 決まった時刻に手順を自動で回す予約機能（予算の上限つき）も搭載。導入は`npm install -g ultracodex`。オープンソース（Apache-2.0）

何が変わった

ultracodexは、ある1本の作業手順を、複数のAIツールで使い回せるようにするツールです。ざっくり言うと、Claude Code（Anthropicのコーディングエージェント）向けに書いた手順を、書き換えないままOpenAIのCodex CLIやOpenCodeでも実行できます。手順はJavaScriptで書き、AIを関数のように呼び出して（`await agent(prompt)`のように）決まった形の答えを受け取る書き方です。この仕組みで、「Claudeが手順を書く→Codexがサンドボックス（隔離された安全な場所）で実行する→Claudeが結果を検証する」といった複数AIの役割分担を1本にまとめられます。ほかに、決まった時刻に手順を自動で回す予約機能（放置運転のための予算上限つき）や、記憶を持たせた複数AIの組織的な運用（試験的）もあります。

誰に関係する

Claude CodeとCodexを両方使う開発者や、AIどうしで作業を分担・自動化させたい人に向いた、上級者向けのツールです。使うにはコマンドで`npm install -g ultracodex`（Node.jsのツールを入れるコマンド）を実行します。ライセンスはApache-2.0です。
