プロジェクト全体を「知識グラフ」にしてAIに検索させる「graphify」。コードの解析は無料・手元で完結

30秒でわかる

  • graphify ↗は、プロジェクト全体を「何が何とつながっているか」の地図（知識グラフ）にするツール
  • AIはファイルを片っ端から読む代わりに、グラフに質問して必要な部分だけを受け取れる
  • コードの解析はAIを使わず手元で行うので無料。資料・PDF・画像・動画もまとめてグラフにできる（こちらはAIを使う）

何が変わった

AIのコーディング道具は、質問に答えるためにたくさんのファイルを読み込み、そのぶんトークン（処理した文字の量）を使います。graphifyは、プロジェクトの中にある関数やファイルの「呼び出す」「読み込む」といった関係をあらかじめ調べ、graph.jsonという1つの地図にまとめておきます。AIに「/graphify .」と頼むと、ブラウザで見られる図（graph.html）、要点をまとめた報告書（GRAPH_REPORT.md）、地図本体（graph.json）の3つができます。あとは「graphify query」で質問すると、関係する部分だけが返ってきます。コードの解析には構文解析の仕組み（tree-sitter）を使うのでAIの利用料がかからず、コードが外部に送られません。約40のプログラミング言語に対応しています。つながりには「コードに書いてある」か「推測した」かの印が付くので、どこまで確かな情報かも見分けられます。

誰に関係する

大きなプロジェクトでAIに作業させていて、読み込みの多さが気になる人に向いています。インストールにはPython 3.10以上が必要で、Windowsでは「winget install astral-sh.uv」でuvを入れてから「uv tool install graphifyy」で導入します。
