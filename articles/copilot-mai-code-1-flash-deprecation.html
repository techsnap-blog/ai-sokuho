GitHub Copilot重要な変更2026-08-12

GitHub Copilotの「MAI-Code-1-Flash」が提供終了へ。9月10日までに新モデルへ切り替えを

30秒でわかる

  • GitHub Copilot（コードを書くのを手伝うAI）で選べるモデルの一つ「MAI-Code-1-Flash」が終了する
  • 2026年9月10日に提供終了。それまでに後継の「MAI-Code-1.1-Flash」へ切り替えが必要
  • 会社で使っている場合は、管理者が設定で新モデルを有効化しないと選べないことがある

何が変わった

GitHub Copilotでは、コード補助に使うAIモデルを選べますが、そのうちの一つ「MAI-Code-1-Flash」が2026年9月10日で提供終了になります。後継として「MAI-Code-1.1-Flash」が用意されるので、この日までに、モデルを指定している設定や連携（ワークフロー・統合）を新しいモデル名に切り替えておく必要があります。会社（Enterprise）で使っている場合は、管理者がCopilotの設定（ポリシー）で新モデルへのアクセスを許可すると、VS Codeやgithub.comのCopilotチャットのモデル選択に出てきます。終了後に古いモデルを消すための手作業は不要です。

誰に関係する

GitHub Copilotで「MAI-Code-1-Flash」を明示的に選んで使っている人に関係します。ふだんモデルを気にせず使っている人は影響が小さいですが、モデル名を指定した設定・自動化がある人は、9月10日までに新モデル名へ差し替えておきましょう。
