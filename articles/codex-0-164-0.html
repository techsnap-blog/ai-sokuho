OpenAI Codex CLI 0.164.0：よく使う指示を10個の枠に保存できる「/presets」が登場

30秒でわかる

  • よく使う指示を10個の番号付きの枠（/presets）に保存し、キーボードのメニューから呼び出せるようになった
  • `/model` と `/permissions` の後ろに設定を書けば、モデル・推論の深さ・速度・権限を1行で切り替えられる
  • 会話の圧縮に失敗すると途中までの要約が履歴に残ってしまう不具合などを修正

何が変わった

Codex（コーディングを手伝うCLI＝コマンドで操作するツール）の0.164.0が公開されました。目玉は`/presets`です。よく使うプロンプトやスラッシュコマンド（`/` で始まる操作コマンド）を番号付きの10個の枠に保存でき、キーボードのメニューから呼び出せます。毎回同じ指示を打ち直さずに済みます。`/model`と`/permissions`は後ろに設定を書けるようになり、モデル、推論の深さ、速度、権限をその場で指定できます。KittyやSixelに対応した端末なら、全画面表示の会話の中で画像をプレビューできます。修正面では、会話の圧縮（長くなった会話を要約して縮める処理）に失敗したとき途中の要約が履歴に残る問題や、セッションを再開すると圧縮済みの履歴が見つからない問題が直りました。Windowsでは、社内のプロキシが認証を求めてきたとき、サインイン中のユーザーの資格情報で通れるようになっています。

誰に関係する

Codexを使っている人に関係します。とくに同じ指示を何度も入力している人や、作業ごとにモデルや権限を切り替えている人は手間が減りそうです。
