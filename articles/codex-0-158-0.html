OpenAI Codex CLI 0.158.0：画像の背景を透明にできるように、コピーや貼り付けも改善

30秒でわかる

  • 画像を作るとき、背景を透明にするよう明示的に頼めるようになった。画像の編集ツールは、会話に載っている画像ファイルをそのまま受け取れる
  • 全画面表示で、選択した文字を自動でコピーする設定や、右クリックで貼り付ける設定が追加。コピーしてもMarkdownの書式が残る
  • Windows・Linux・macOSの安全機能（サンドボックス）まわりの不具合を多数修正

何が変わった

Codex（コーディングを手伝うCLI＝コマンドで操作するツール）の0.158.0が公開されました。画像まわりでは、画像生成で透明な背景を明示的に頼めるようになり、編集ツールも会話に載っている画像ファイルをそのまま扱えます。操作面では、全画面表示で文字を選ぶだけでコピーされる設定と、右クリックで貼り付けられる設定を選べます。会話の記録をコピーしたとき、Markdownの書式も保たれます。設定まわりでは、MCP（AIが外部ツールとやり取りする仕組み）サーバーにOAuthのクライアントシークレットを登録でき、`codex mcp add --oauth-client-secret` で追加できます。裏方サーバーとのWebSocket接続にも、トークンによる保護が付きました。権限の確認では、管理者権限が要るコマンドの入力承認が標準になっています。不具合の修正では、Windowsのサンドボックスが標準のパスや保存済みの認証情報で失敗する問題、Linuxのサンドボックスが起動しない問題、macOSで承認の確認が多すぎる問題などが直りました。公式は、全体で約120件のコミットが入った更新としています。

誰に関係する

Codexを使っている人に関係します。とくに全画面表示でコピーや貼り付けがしにくかった人や、Windowsで安全機能まわりのエラーに当たっていた人は、更新の恩恵を受けやすい内容です。
