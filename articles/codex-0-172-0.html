OpenAI Codex CLI 0.172.0：検索結果から過去の会話をそのまま開けるように

30秒でわかる

  • 検索結果や会話の記録に出るリンクから、保存した会話や作業中の子エージェントを開ける
  • 「/mcp lo」でTabを押すと「/mcp login」になるなど、スラッシュコマンドの続きをTabで補える
  • 中断して再開したとき、保存していた権限や作業フォルダが元に戻るようになった

何が変わった

Codex（コーディングを手伝うCLI＝コマンドで操作するツール）の0.172.0が公開されました。検索結果や会話の記録に出てくるリンクをたどって、保存済みの会話や、作業を分担している子エージェントの画面をターミナルで開けるようになりました。前にやった作業を探して続きに戻るのが楽になります。 「/mcp」などのスラッシュコマンドでは、途中まで打ってTabを押すと続きが補われます。ほかに、MCPサーバー（AIが外部ツールとやりとりする窓口）のうち使用が任意のものは、初めて使うときに起動するのが標準になりました。会社などで使うときに、AmazonのAIサービス（Amazon Bedrock）を接続先として選べるようにもなっています。 修正面では、`codex exec resume` で作業を再開したとき、保存していた権限設定や作業フォルダが戻るようになりました。料金の上限に達したときには、どの上限に引っかかったかが表示されます。

誰に関係する

Codexを使っている人に関係します。過去の会話を行き来しながら作業する人には便利な更新です。
