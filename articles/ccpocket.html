スマホからCodex・Claude Codeを動かせるモバイルアプリ「CC Pocket」

30秒でわかる

  • スマホ（iOS/Android）やタブレットから、Codex・Claude Codeを操作できるモバイルアプリ。外出先でも作業の指示・承認・結果確認ができる
  • 自分のPCで動かす橋渡し役（Bridge Server）とつなぐので、コードを外部サービスに上げず自分のPCに置いたまま使える
  • 無料・オープンソース（MITライセンス）。PC側でBridgeを起動し、アプリでQRコードを読むだけで接続（GitHub ↗）

何が変わった

CC Pocketは、スマホ・タブレット・PCから、Codex や Claude Code といったコーディングエージェント（人の代わりにコードを書いたり直したりを最後まで進めるAI）を操作できるアプリです。仕組みは「スマホアプリ ←→ 自分のPCで動く橋渡し役（Bridge Server）←→ Codex / Claude」の3段構成で、アプリとPCはWebSocket（つなぎっぱなしで双方向にやり取りする通信）でつながります。この形なので、コードを外部のサーバーにアップロードせず、自分のPCに置いたまま、作業の開始・途中の承認・結果の確認だけを手元のスマホから行えます。

誰に関係する

外出先や移動中でも、PCで走らせているAIの作業を確認・承認したい開発者に向いています。使うにはPC側にエージェントのCLI（黒い画面で使うアプリ）とNode.js 20.18.1以上が必要で、`npx @ccpocket/bridge@latest`で橋渡し役を起動し、アプリでQRコードを読み取ると接続できます。
