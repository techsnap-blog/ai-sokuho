Claude CodeやCodexをスマホからも操作できる「T3 Code」。無料のオープンソース

30秒でわかる

  • T3 Code ↗は、Claude Code・Codex・Cursorなど10種類以上のコーディングAIを1つの画面でまとめて扱えるアプリ
  • パソコンで動かしているAIの作業を、スマホやブラウザからも確認・指示できる
  • MITライセンスの無料オープンソース。AIの料金は、すでに契約しているプランをそのまま使う

何が変わった

Claude CodeやCodexは、本来はターミナル（黒い画面でコマンドを打つアプリ）で使う道具です。T3 Codeを使うと、それらを1つの見やすい画面からまとめて操作できます。対応するAIは、Claude Code、Codex、Cursor、OpenCode、Kiroなどです。パソコンに入っているAIなら、T3 Codeから動かせるとしています。 どの端末から開いても、同じ会話の続きが見られます。AIは自分のパソコンで動かしたまま、同じネットワーク内か、Tailscale（離れた端末同士を安全につなぐサービス）などを通して、スマホアプリやブラウザから接続します。外出先でAIの作業の進み具合を見て、次の指示を出すといった使い方ができます。 アプリはMac・Windows・Linux向けのほか、iPhone・Android向けもあります。Windowsなら `winget install T3Tools.T3Code` でインストールできます。先にClaude Codeなら `claude auth login`、Codexなら `codex login` でサインインしておく必要があります。

誰に関係する

Claude CodeやCodexを使っていて、パソコンの前を離れても作業を見たい人や、複数のAIを切り替えて使っている人に向いています。
