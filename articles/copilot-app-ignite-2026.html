GitHub Copilotアプリが、ブラウザ操作とAzure DevOpsに対応（プレビュー）。社内GitHubへの接続は正式提供

30秒でわかる

  • ログイン済みのChromeやEdgeで、Copilotがフォーム入力・情報集め・作ったWebアプリの動作確認をできるようになった（プレビュー）
  • Azure DevOpsのリポジトリでも、ブランチ作成からプルリクエスト、レビュー指摘の修正までをアプリ内でまとめてできる（プレビュー）
  • 社内に置くGitHub Enterprise Serverとの接続が正式提供に（アプリ1.2.0以降）

何が変わった

GitHub Copilotアプリに、Microsoftのイベント「Ignite」に合わせた3つの更新が入りました。 1つ目はブラウザ操作（browser use）です。Chrome用の「GitHub Copilot」拡張機能を入れると、すでにログインしているChromeやEdgeで、Copilotがフォームに入力したり、Webページから情報を集めたり、作っているWebアプリを動かして不具合を確かめたりできます。作業は、ほかのタブとは分けたタブグループの中で行います。初期設定ではオフで、設定の「Computer Use」で有効にします。Copilot CLIやVS Codeなどでも使えます。 2つ目は、Microsoftの開発管理サービスAzure DevOpsに置いたコードへの対応です。リポジトリ（コードの保管場所）を取り込み、AIにブランチを作らせてコードを直し、プルリクエスト（変更を取り込む前に確認する単位）を出すまでをアプリ内で行えます。レビューの指摘に「Fix」を押すとAIが直します。 3つ目は、会社が自前で運用するGitHub Enterprise Server（GHES）への接続で、これまでの試験提供から正式提供になりました。

誰に関係する

GitHub Copilotアプリを使う開発者に関係します。ブラウザでの定型作業や動作確認をAIに任せたい人、Azure DevOpsや社内のGitHubを使っている会社の開発者向けの更新です。
