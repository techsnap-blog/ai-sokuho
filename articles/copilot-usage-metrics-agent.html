GitHub Copilotの利用状況データに「AIエージェント別」の項目。どのAIがどれだけ使われたか分かる

30秒でわかる

  • Copilotの利用状況データに、AIエージェント別の内訳が追加
  • どのAIエージェントが何回使われたか（起動回数・セッション数など）が分かる
  • 勘ではなく実際の使用実績にもとづいて、導入や契約を判断できる

何が変わった

GitHub Copilotの利用状況を取得する仕組み(API)に、外部製のAIエージェントごとの利用データが加わりました。企業・組織・個人それぞれのレポートに、エージェント名・識別ID・利用者が起こした操作の回数・セッション数といった項目が入ります。狙いは、どのAIエージェントがどれだけ使われているかを個別に把握し、導入や契約(ライセンス)の判断を、勘ではなく実際の利用実績にもとづいて行えるようにすることです。閲覧できるのは、企業オーナーや請求管理者、組織オーナー、権限を持つ利用者で、利用状況の計測ポリシーを有効にしている必要があります。

誰に関係する

チームや会社でCopilotのコストと使われ方を管理する人に関係します（上級者向け）。AIエージェントごとの使用量を見て、無駄や必要な契約を見極められます。
