GitHub CopilotのAIコードレビューに「力の入れ具合」設定。簡単な修正は軽く、重要な変更は入念に

30秒でわかる

  • AIによるコードレビューの「深さ」を、変更の重要度に応じて選べるように（正式提供）
  • 簡単な変更向けの「Lite」と、複雑・セキュリティ上重要な変更を入念に見る「Balanced」の2段階
  • レビューにはどの深さで見たかが表示され、組織で標準値も設定できる

何が変わった

GitHub CopilotのAIコードレビュー（変更内容をAIが点検する機能）で、レビューの力の入れ具合を選ぶ設定が正式提供になりました。簡単で定型的な変更は「Lite」で軽く、大きい・複雑・セキュリティ上重要な変更は「Balanced」で入念に、と使い分けられます。1回ごとに深さを選んでも標準設定には影響せず、実際にどの深さでレビューしたかが表示されます。組織の管理者は組織全体の初期値を設定でき、各リポジトリはそれを引き継ぎます。対象はCopilot Pro・Pro+・Max・Business・Enterprise。

誰に関係する

GitHubでコードレビューを受ける・依頼する開発者に関係します。ちょっとした修正はサッと、重要な変更はしっかり、とレビューの手間を調整できます。
