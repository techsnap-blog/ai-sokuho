ターミナルで動くQwen製のAIコーディング相棒「Qwen Code」

30秒でわかる

  • ターミナル(コマンドで操作する黒い画面)から指示すると、コードの作成・修正・デバッグを自分で進めるAIエージェント
  • QwenのほかOpenAI・Anthropic・Gemini、さらに自分のPC内で動くAI(Ollama/vLLM)にも切り替え可能＝1つの会社に縛られない
  • 無料・オープンソース(Apache 2.0)。npmで導入、VS Code等のエディタ連携もあり(GitHub ↗)

何が変わった

Qwen Codeは、ターミナルから日本語や英語で指示すると、その場でコードを書いたり、バグを直したり、複数の手順を自分で進めてくれるAIエージェント(人の代わりに作業を最後までこなすAI)です。コードレビュー・一括処理・デバッグ・繰り返し作業といったよく使う作業が「スキル」として最初から入っており、外部ツールとやり取りするMCP(AIが外部の道具を使う共通の仕組み)にも対応します。大きな特徴は、動かすAIをQwenに固定せず、OpenAI・Anthropic・Gemini、あるいは自分のPCやサーバー内で動かすAI(Ollama/vLLM)へ自由に切り替えられる点です。TypeScript・Python・Java向けのSDK(開発者が自分のプログラムに組み込む部品)も用意されています。

誰に関係する

黒い画面での作業に抵抗がない開発者や、AIに実際のコード作業を任せたい人に向いています。導入は`npm install -g @qwen-code/qwen-code@latest`で、Node.js 22以上が必要です。VS Code・JetBrains・Zedといったエディタからも使えます。
