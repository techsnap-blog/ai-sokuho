OpenAI Codex CLI 0.157.0：新モデル「GPT-6 Sol」「GPT-6 Luna」に対応、会話の分岐も可能に

30秒でわかる

  • 新モデル「GPT-6 Sol」「GPT-6 Luna」がCodexで使えるようになった。Amazon Bedrock（Amazonのクラウド経由でAIを使うサービス）にも対応
  • 古いモデルを使っていると、新しいモデルへの乗り換えを案内してくれる
  • 会話を途中から枝分かれ（フォーク）させる機能を追加。書きかけの入力や待ち行列の指示も引き継がれる

何が変わった

Codex（コーディングを手伝うCLI＝コマンドで操作するツール）の0.157.0で、OpenAIの新しいモデル「GPT-6 Sol」と「GPT-6 Luna」を選べるようになりました。Amazon Bedrock経由でも使え、古いモデルを使っている人には乗り換えを促す案内が出ます。もう一つの新機能が会話のフォークです。`f` キーで今の会話を枝分かれさせられるので、別の方針を試したいときに元の流れを壊さずに済みます。書きかけの入力や、順番待ちにしていた指示もそのまま引き継がれます。ほかに、会話の記録を全画面で表示する設定が標準になり（Shiftを押しながらクリックで文字を選べる）、条件を満たす対話では裏方のサーバーが自動で起動するようになりました。`/import` コマンドは、裏方サーバーを使うセッションでも使えるようになっています。不具合の修正では、スレッドを切り替えても音声会話が途切れない、送信前の質問の下書きが入力欄に戻る、ファイルのアップロードの再試行と待ち時間の延長（5分）などが入りました。

誰に関係する

Codexを使っている人、とくに新しいGPT-6系のモデルをコーディングで試したい人に関係します。Amazon Bedrock経由でAIを使っている開発チームにも関係します。
