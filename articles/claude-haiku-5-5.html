Anthropicが「Claude Haiku 5.5」を公開。Haiku 4.5より平均約75%安く、Claude Codeでも標準のHaikuに

30秒でわかる

  • Claude 5.5シリーズの3つ目、小型で速い「Haiku 5.5」が登場。Anthropicは「最も安く、最も速い」モデルと説明している
  • API料金は100万トークンあたり入力$0.10・出力$0.50。Haiku 4.5（入力$1・出力$5）より平均約75%安いとされる
  • Claude Code v2.1.293で標準のHaikuモデルになった。100万トークンの長い文章を一度に扱える

何が変わった

Anthropicは、Opus 5.5とSonnet 5.5に続く小型モデルClaude Haiku 5.5 ↗を公開しました。要約や分類のように量が多く費用を抑えたい作業、カスタマーサポートの即時応答、ブラウザ操作など速さが要る用途を想定しています。Claude Codeでは、Opus 5.5やSonnet 5.5の下で動く補助役（サブエージェント）としての使い方も挙げられています。Haikuクラスで初めて、考える深さ（effort）を調整できるようになりました。料金は100万トークン（処理する文字量の単位）あたり入力$0.10・出力$0.50で、10万トークンを超える長い指示では入力$0.50・出力$2.50です。Anthropicの発表によると、パソコン操作の性能を測るOSWorld 2.1（オフライン版）ではHaiku 4.5の15.7%から72.4%に上がりました。Sonnet 5.5の83.9%には届きません。同じ日に出たClaude Code v2.1.293で、Haiku 5.5（claude-haiku-5-5）がAnthropic APIの標準Haikuになりました。

誰に関係する

APIでClaudeを大量に使う開発者や、費用を抑えたい人に関係します。Amazon Web Services、Google Cloud、Microsoft Azureでも使えます。
