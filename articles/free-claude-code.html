Claude Codeを他社や手元のAIモデルで動かす「free-claude-code」。無料枠のモデルにも切り替え可能

30秒でわかる

  • free-claude-code ↗は、Claude Codeなど11種類のAIコーディング道具を、好きなモデルで動かせるようにする中継ツール
  • 61のサービスに対応し、無料枠のモデルや自分のPCで動くモデルも選べる
  • モデルが応答しなくなったら次のモデルへ自動で切り替え、作業を止めずに続けられる

何が変わった

free-claude-code（略称FCC）は、AIコーディング道具とAIモデルの間に入る中継役です。Claude Code、Codex、OpenCode、Clineなど11種類の道具を、FCCに登録したモデルで動かせます。モデルは無料枠のもの、有料のもの、サブスクリプション、自分のPCで動くものから選べます。再試行しても応答がないときは次に設定したモデルへ自動で移るため、その回のやり取りをやり直す必要がありません。導入はWindowsならPowerShellの1行で、起動すると管理画面が開き、そこでサービスの鍵（APIキー）を登録してモデルを選びます。あとは「fcc-claude」のようなコマンドで各道具を起動します。オプションで、コマンドの出力や道具の結果を圧縮して読み込み量を減らす仕組み（RTK・Headroom）も使えます。

誰に関係する

Claude Codeの操作感のまま、他社のモデルや無料枠のモデルも使ってみたい人に向いています。
