AIにデザインの“引き出し”を渡すスキル「UI UX Pro Max」。配色やフォントを根拠つきで提案

30秒でわかる

  • UI UX Pro Max ↗は、AIに画面デザインの知識を足すスキル
  • 79種類の見た目のスタイル、192種類の配色、74通りのフォントの組み合わせなどをデータとして持ち、目的に合うものを選ばせる
  • Claude Codeなら2つのコマンドで入る。React・Vue・Flutterなど22種類の開発環境に対応

何が変わった

AIに画面を作らせると、どれも似たような見た目になりがちです。UI UX Pro Maxは、デザインの判断材料をデータとしてAIに渡すスキル（AIに特定の作業をさせる追加ルール）です。中には、すりガラス風やミニマルなどの見た目のスタイル79種類、業種ごとの配色192種類、Googleフォントを使ったフォントの組み合わせ74通りなどが入っています。目玉の「デザインシステム生成」では、たとえば「スパのサイト」のように作りたいものを伝えると、ページの構成、スタイル、配色、フォントをひとまとめにした方針を理由つきで出してくれます。ざっくり言うと、AIにデザイナーの資料棚を持たせるイメージです。ReactやNext.js、Vue、Flutter、SwiftUIなど22種類の開発環境に対応しています。

誰に関係する

Claude CodeやCursorなどでWebサイトやアプリの画面を作らせている人、とくに見た目がいつも同じになって困っている人に向いています。
