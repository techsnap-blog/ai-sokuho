Claude CodeのRemote Controlが正式に：PCで動かしているClaude Codeをスマホから操作・継続できる

30秒でわかる

  • PCで動かしているClaude Codeのセッションを、スマホアプリやブラウザからそのまま続けて操作できる（Remote Control ↗）
  • 作業はあくまでPC上で走り続ける＝自分のファイルやMCP・プロジェクト設定はPCのまま使える（クラウドで動くClaude Code on the webとは別物）
  • Wi-Fiが切れたりPCがスリープしても、復帰後に自動で再接続。途中経過も後からまとめて届く

何が変わった

PCのターミナルで動かしているClaude Codeに、外出先のiPhone・Androidアプリや別PCのブラウザ（claude.ai/code）からアクセスして、同じ会話の続きを操作できるようになりました。ポイントは、処理そのものはPC上で走ったままだということ。ファイルの読み書きやコマンド実行、MCP（AIが外部ツールとやり取りする仕組み）やプロジェクト設定は全部PC側に残り、スマホ・ブラウザは「そのPCのセッションをのぞく窓」として振る舞います。使い方はPCで `claude remote-control`（または `claude --remote-control`、実行中なら `/remote-control`）と打つと接続用URLとQRコードが出るので、スマホの「Claude」アプリで読み取って繋ぐ形です。スマホから写真やファイルを送って作業を頼むこともできます。PCがスリープしたりWi-Fiが切れても、オンラインに戻れば自動で繋ぎ直し、その間に進んだサブエージェントの経過もまとめて届きます。なお「スマホからPCを起動する」わけではなく、起動はPC側で行い、それをスマホから引き継ぐ・操作するという形です。

誰に関係する

自宅PCで長い作業をClaude Codeに任せて、外出先や別の部屋のスマホから進捗を見たり指示を足したい人に便利です。Pro・Max・Team・Enterpriseの有料プランで使えます（APIキー利用は非対応、Team/Enterpriseは管理者が有効化する必要あり）。
