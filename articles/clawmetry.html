Claude CodeやCodexの「作業の中身」を可視化する無料ツール「ClawMetry」

30秒でわかる

  • Claude Code・Codex・Cursor・Gemini CLIなど30種類以上のコーディングAIの動きを、1つのダッシュボードでまとめて監視できる
  • 設定不要（zero-config）でPC上のAIを自動検出。費用・トークン使用量・ツール呼び出し・会話の記録（再生も可）・危険な操作の承認待ちなどを表示
  • 導入は`pip install clawmetry && clawmetry`で、ブラウザの`localhost:8900`で開く。無料・オープンソース（MITライセンス）

何が変わった

ClawMetryは、複数のコーディングAIエージェント（人の代わりにコードを書いたり直したりを進めるAI）が、実際に何をしているかを見える化する監視ツールです。ざっくり言うと、AIの作業を横から覗いて「どれだけお金とトークンを使ったか」「どんなツールを動かしたか」「今どんな判断をしているか」を1画面にまとめて表示します。対応するのはClaude Code・OpenAI Codex・Cursor・GitHub Copilot・Gemini CLI・Aiderなど30種類以上です。特徴は設定不要で、PCに入っているAIを自動で見つけて監視を始める点です。会話の記録を後から再生する機能、費用とトークンをAIごとに集計する機能、危険な操作の前に人の承認を挟む「承認ゲート」なども備えます。

誰に関係する

Claude CodeやCodexなどを日常的に動かし、費用や作業内容を把握・管理したい開発者やチームに向いています。使うには、コマンドで`pip install clawmetry`（PythonのAI関連ツールを入れるコマンド）を実行して起動し、ブラウザで`http://localhost:8900`を開くだけです。無料でMITライセンスのため、業務でも比較的使いやすい部類です。
