コーディングAIにコードの地図とチームの決めごとを渡す「Trail-code」。開発元の測定でツール呼び出し46%減

30秒でわかる

  • Trail-code ↗は、コードの地図を作ってAIに渡し、必要なファイルへまっすぐたどり着かせるツール
  • 会話の中で決めたことを「learnings（学び）」としてファイルに残し、次の作業やチームの仲間のAIに引き継げる
  • 開発元の測定では、ツール呼び出し46%減・作業時間60%減。以前の名前は「Graft」

何が変わった

コーディング用のAIは、作業を始めるたびにファイルを1つずつ開いて中身を探します。Trail-codeは、すべての関数と、それを呼び出している場所を一覧にした「コードの地図」を手元のパソコンで作り、AIに渡します。AIは目当てのファイルや関数へまっすぐ向かえるので、ある変更がどこに影響するかも見えやすくなります。もう1つの柱が「learnings（学び）」です。作業中の会話から、チームで決めたことや避けた方法を読めるファイルとして残します。`trail check` を使うと、仲間の決定を知らずに元に戻すような変更を、プルリクエスト（変更の取り込み依頼）の前に知らせてくれます。開発元の測定では、162回の実行でツール呼び出しが46%、作業時間が60%減ったとしています。インストールは `npm install -g @trailhq/trail-code` のあと `trail init` を実行します。

誰に関係する

Claude CodeやCodexでの作業が、ファイル探しに時間がかかって遅いと感じている人や、チームで同じコードをAIに触らせている人に向いています。
