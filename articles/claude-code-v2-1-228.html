Claude Code v2.1.228：表示崩れやWindowsのGit検出を修正、同期スキルの安全対策を強化

30秒でわかる

  • Claude Code（クロード・コード＝ターミナルで動くAIの開発支援ツール）がv2.1.228に更新
  • レイアウトの不具合後に画面の再描画が止まる問題を修正
  • WindowsでGitが検出されない問題を修正（Git Bashを親フォルダから起動した場合）
  • claude.aiから同期するスキルの安全対策を強化（ローカルのコマンドを乗っ取らない・危険な自動実行をしない）

何が変わった

AnthropicのAI開発支援ツール「Claude Code ↗」がv2.1.228を公開しました（Claude Code＝黒い画面＝ターミナル上でAIにコードを書かせたり操作させたりするツール）。今回は不具合修正が中心です。主なものは、画面の表示が崩れたあとに再描画が完全に止まってしまう問題や、WindowsでGit（変更履歴を管理する仕組み）が見つからない問題、モデルを切り替えたのに元に戻ってしまう問題などの修正です。加えて、claude.aiから同期されるスキル（あらかじめ用意された作業手順）のセキュリティを強化し、ローカル（自分のPC）のコマンドを勝手に上書きしない・説明文を安全に整えるなどの対策が入りました。改善では、新しいモデルがファイルを読み込まずに上書きできるようになるなど、細かな使い勝手の向上も含まれます。全体として、新機能というより安定性と安全性を高める更新です。

誰に関係する

Claude Codeを使っている開発者・ライトユーザーに関係します。特にWindowsで使っている人や、claude.aiのスキルを同期して使っている人は更新しておくとよいでしょう。更新は通常のアップデート手順で行えます。
