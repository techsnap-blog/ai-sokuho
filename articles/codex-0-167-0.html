OpenAI Codex CLI 0.167.0：エージェントの管理画面で「未読の結果」が分かるように。貼った画像のプレビューにも対応

30秒でわかる

  • `codex agents --no-daemon` で開く管理画面とセッション選択画面に、まだ見ていない結果の印が付く
  • 入力欄で、手元の画像を添付前にプレビューできる。会話中に出てきた画像のパスはクリックで開ける
  • 接続先を切り替えても書きかけの入力が消えない。セッションの再開に失敗しても、記録を読んで続きを書ける

何が変わった

Codex（コーディングを手伝うCLI＝コマンドで操作するツール）の0.167.0が公開されました。`codex agents --no-daemon` で開くエージェントの管理画面と、セッションを選ぶ画面で、まだ確認していない結果に印が付くようになりました。複数のエージェントに作業を任せているとき、どれが終わったかを見落としにくくなります。入力欄では、手元の画像を添付する前にプレビューできます。セッション選択画面からは、書きかけの入力を残したまま接続先を切り替えられます。APIキーやクラウド事業者でのサインインは「別の方法でサインイン」の中にまとめられました。修正面では、モデルの提供元を切り替えても保存済みの会話が見えなくなる問題が直りました。`Ctrl+L` で画面を消しても、それまでのやり取りは `Ctrl+T` で見返せます。

誰に関係する

Codexを使っている人に関係します。とくに複数のエージェントに同時に作業させている人は、終わった作業を拾いやすくなります。
