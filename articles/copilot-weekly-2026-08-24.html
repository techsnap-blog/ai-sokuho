GitHub Copilotが週次更新、Slack・Teamsでの相談やアプリのカスタマイズ集約に対応

30秒でわかる

  • GitHub Copilot（プログラミングを手伝うAI）の週次アップデート
  • SlackやMicrosoft Teamsの会話から「@GitHub」と呼びかけて、調べ物や作業を頼めるようになった
  • アプリの設定（拡張機能・プラグイン等）が「カスタマイズ」タブ1か所に集約され、CLI（コマンドで操作する版）は中断したセッションを復元できるように

何が変わった

GitHub Copilot ↗の8月24日週の更新では、使う場所と設定まわりが広がりました。SlackとMicrosoft Teamsのチャット内で「@GitHub」と呼びかけると、問題の調査や作業の計画・変更をチームで一緒に進められるようになっています。アプリ版では、MCP（AIが外部ツールとやり取りする仕組み）サーバーやプラグイン、スキルといった設定が「カスタマイズ」タブにまとまり、タブを左右に分けて並べる表示も可能になりました。CLI（黒い画面＝コマンドで操作する版）では、予期せず終了したセッションを復元できるようになり、動作も高速化しています。ざっくり言うと、チームでの使いやすさと設定の見通しが良くなった更新です。

誰に関係する

GitHub Copilotをチームで使っている人や、SlackやTeamsで開発の相談をしたい人に関係します。多くは開発者向けの機能です。
