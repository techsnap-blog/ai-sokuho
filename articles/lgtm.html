「LGTM」— GitHub Copilotに、変更したコードをレビューさせるVS Code拡張

30秒でわかる

  • Copilot Chat に自分の変更コードをレビューさせ、バグや改善点を挙げてもらえる拡張機能
  • 指摘は深刻度順に並び、行番号をクリックすればその場所へ飛べる
  • 指摘からそのまま修正を適用できる。Copilot Chat は無料プランでも動く

何が変わった

LGTM は VS Code に入れて使う拡張機能（エディタに後から足せる追加機能）です。プルリクエスト（他の人に取り込んでもらうための変更のまとまり）や、まだコミットしていない手元の変更を対象に、GitHub Copilot Chat へレビューを依頼できます。実行はコマンドパレットから「LGTM: Start Code Review...」を選ぶか、チャットで `/review` と打つだけです。返ってきた指摘はファイルごとにまとまり、深刻度の高い順に並びます。行番号がリンクになっていて、クリックすれば該当箇所に移動できます。指摘の内容をそのまま修正として当てることもできます。レビューはチャットに残るので、「なぜこれが問題なのか」を続けて質問できます。リポジトリのルールを書いた `AGENTS.md` が既定で参考資料として読み込まれ、設定から追加のファイルや共通の指示文を足すこともできます。

誰に関係する

VS Code と GitHub Copilot Chat を使っている人に関係します。Copilot Chat は無料プランでも有料プランでも利用できるとされています。GitHub Pull Requests 拡張や Atlassian Bitbucket 拡張を入れていれば、プルリクエスト単位のレビューにも対応します。なお、レビュー対象のソースコードとコミットメッセージは、設定したAIモデルの提供元へ送られます。社外に出せないコードを扱うときは、この点を確認してから使う必要があります。
