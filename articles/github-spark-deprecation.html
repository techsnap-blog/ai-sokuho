GitHub Copilot重要な変更2026-08-04

GitHub Spark が提供終了へ。8月31日までにアプリの書き出しが必要

30秒でわかる

  • GitHub Spark（＝言葉で指示してアプリを作れるツール）が終了に向かう
  • 2026年8月4日から、新規登録と新しいアプリの作成ができなくなった
  • 既存ユーザーは2026年8月31日までにアプリのコードを書き出し（エクスポート）しないと、編集できなくなる

何が変わった

GitHub Sparkは、言葉で指示するだけでアプリを作れるGitHubのツールでしたが、github.com上での提供を終えることになりました。2026年8月4日以降は新規の登録も、新しいアプリの作成もできません。すでに使っている人も、2026年8月31日を過ぎるとアプリにアクセス・編集できなくなるため、それまでにコードの書き出しが必要です（Sparkの画面のメニューから「Create repository」でリポジトリ＝コードの保管場所として書き出せます）。また、SparkのAI機能が使っていた「GitHub Models」は7月30日にすでに終了しているので、AI機能を動かし続けるには自分で別のAIサービス（推論プロバイダ）を用意し、そのAPIキーと料金を自分で管理する必要があります。GitHubは今後、VS CodeやCopilot CLI、GitHub Copilotアプリの統合的な使い方への移行をすすめています。

誰に関係する

GitHub Sparkでアプリを作っている人は、8月31日までにコードの書き出しを。とくにSparkのAI機能（llm()）を使っているアプリは、そのままでは動かなくなるため、別のAIサービスへの差し替えが必要です。これから同じことをしたい人は、Copilot系のツールが移行先の候補になります。
