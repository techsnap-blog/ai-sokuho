GitHub Copilot 週まとめ（8月3日週）。スマホ・CLI・VS Codeがそれぞれ使いやすく

30秒でわかる

  • スマホのCopilotアプリ: どのAIモデルが答えたか表示、別の質問を横で試せる「/side」を追加
  • コマンド版Copilot(CLI): 会話とファイルを元に戻せる「/rewind」が、Gitなしでも使えるように
  • VS Code: Webページの見たい部分をクリックして指示できる、話しかけて入力（多言語対応）などを追加

何が変わった

GitHub Copilotの、8月3日の週に出た更新のまとめです。スマホ向けのCopilotアプリでは、自動でモデルを選ぶ「Auto」がどのAIモデルで答えたか（AIクレジットの消費も）を表示するようになり、「/side」で今の会話を止めずに別の質問を横で試せるようになりました。コマンドで使うCopilot（CLI＝黒い画面から操作する版）では、複数の会話を切り替える一覧が付き、「/rewind」で会話とファイルを前の状態に戻す操作がGitなしでもできるように。VS Code（人気のコード編集アプリ）では、Webページ上の見せたい部分を選んでコメントを付け、そのままAIに指示できる機能や、話しかけて文字入力できる音声入力（多言語・自動判別）、今の作業を止めずに横で質問できる「/btw」などが加わりました。いずれも正式提供（一部はお試し扱いの実験機能）です。

誰に関係する

Copilotを日常的に使う人全般に関係します。とくに、スマホから使う人・コマンド版で作業する人・VS Codeを使う人は、それぞれ今回の改善が効いてきます。実験扱いの機能は今後変わる可能性があります。
