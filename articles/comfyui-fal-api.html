ComfyUIからfal.aiの約1,400のAIモデルを呼び出せるノード集「ComfyUI-fal-API」。画像・動画・音声・文章をクラウド生成

30秒でわかる

  • ComfyUIから、クラウドサービス fal.ai の約1,400のAIモデルを呼び出せる追加ノード集「ComfyUI-fal-API」の紹介
  • 画像・動画・音声・文章生成（LLM）・画像を読むAI（VLM）・3Dまで、手元にGPUがなくてもクラウドで動かせる
  • 利用には fal.ai のAPIキー（利用者を識別する鍵・無料で取得）を1つ入れるだけ

何が変わった

画像・動画生成を部品（ノード）をつないで組み立てるツール「ComfyUI」に、クラウドサービス fal.ai の約1,400のAIモデルを呼び出せる追加ノード集「ComfyUI-fal-API ↗」があります。fal.ai は、多くのAIモデルをネット越しに使えるようまとめたサービスです。このノード集を入れると、処理を自分のPCではなく fal.ai のサーバー（クラウド）に任せられるため、手元に高性能なGPU（画像処理用の部品）がなくても重い生成を実行できます。対応は幅広く、画像・動画・音声の生成、文章を扱うLLM、画像の内容を読み取るVLM、3Dまで含まれます。ノードは自動生成の約1,400種類に加え、使いやすく整えた約90種類が用意されています。使うにはfal.ai のAPIキー（無料で取得できる利用者識別の鍵）を設定ファイルか環境変数に入れ、ComfyUIを再起動するだけです。導入はComfyUI Manager（拡張の追加ツール）からが簡単で、生成結果の一時保存や使いすぎ防止の設定、複数生成の同時実行にも対応します。

誰に関係する

高性能GPUを持たずに、fal.ai の多数のAIモデルをComfyUIの操作画面のまままとめて試したい人に関係します。クラウドで生成する分は fal.ai 側の料金体系に沿って費用がかかるため、どのモデルにいくらかかるかは公式で確認しておくと安心です。
