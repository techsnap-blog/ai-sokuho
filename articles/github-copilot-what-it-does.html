GitHub Copilotでできることまとめ：エディタ内のコード補完・提案に強いAI

30秒でわかる

  • 特にエディタ内のコード補完・提案に強い。書きかけのコードの続きをその場で提示してくれる
  • GitHub Copilot（ギットハブ コパイロット）は、GitHubが提供するコーディング支援AI
  • VS Codeなどのエディタやチャットで相談でき、GitHubとの連携が強い。※料金・対応範囲は公式で確認

何が変わった

「GitHub Copilot（ギットハブ コパイロット）」は、GitHubが提供するコーディング支援AIです。最大の持ち味は、特にエディタの中でコードを書いている最中に、続きのコードを補完・提案してくれること。コメントで「〇〇する関数」と書くと中身を提示したり、チャットでコードの相談・修正を頼んだりできます。VS CodeやVisual Studioなど主要なエディタで使え、GitHub（ソースコードの保管・共有サービス）との連携が強いのも特徴です。個人向け・チーム向けのプランがあり、無料で使える範囲も用意されています。対応環境や料金、機能は変わることがあるため、公式で確認してください。AIの提案は必ず内容を確認してから採用しましょう。

誰に関係する

コードを書く人、エディタ内での補完や提案でテンポよく開発したい人に向いています。GitHubやVS Codeを使っている人ほど恩恵が大きい一方、AIの提案は必ず確認してから反映する前提で使いましょう。
