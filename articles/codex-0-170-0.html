OpenAI Codex CLI 0.170.0：ターミナル画面からリアルタイムの音声通話ができるように

30秒でわかる

  • ターミナル画面で、声でリアルタイムにやりとりする通話に対応した
  • クラウドでの会話は、接続が切れても自動でつなぎ直しやすくなり、進行中の作業も保たれる
  • 同じ名前のMCPサーバーを環境ごとに使い分ける機能が、試験的に加わった

何が変わった

Codex（コーディングを手伝うCLI＝コマンドで操作するツール）の0.170.0が公開されました。ターミナル画面（TUI）で、リアルタイムの音声通話ができるようになりました。通話の接続には、ブラウザのビデオ通話などで使われるWebRTCという仕組みを使います。 ほかに、MCPサーバー（AIが外部ツールとやりとりする窓口）で、同じ名前のものを環境ごとに使い分ける機能が試験的に入りました。修正面では、クラウドでの会話が途切れたときの自動再接続が良くなり、つなぎ直したときに進行中の作業も失われにくくなっています。Windowsでのファイル置き換えの不具合や、ファイル検索で同じ結果が重複して出る問題も直りました。

誰に関係する

Codexを使っている人に関係します。キーボードを打たずに、声でCodexとやりとりしたい人には試す価値のある更新です。
