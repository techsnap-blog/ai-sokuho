Hermes Agent重要な変更2026-11-07

Hermes Agent v0.23.0：デスクトップ版の画面をブラウザで開けるように。どの画面から開いても同じ会話が続く

30秒でわかる

  • デスクトップ版と同じ作業画面を、ブラウザのタブで開けるWebアプリが追加された（初期設定ではオフ）
  • 1台につき1つのゲートウェイがすべての会話を管理する形に変わり、どの画面から開いても同じ会話を続けられる
  • 有料ツールに使う金額の上限を決められるようになった。古いブラウザ操作ツールは削除された

何が変わった

Hermes Agent（Nous Researchが作る、手元で動かすAIエージェント）のv0.23.0が公開されました。新しいWebアプリで、デスクトップ版と同じ作業画面をブラウザのタブから開けます。初期設定ではオフで、外から開く場合はサインインを挟めます。仕組みも変わり、パソコン1台につき1つのゲートウェイ（会話をまとめて受け持つ窓口のプログラム）がすべてのセッションを管理します。CLI、デスクトップ版、エディター、チャットボット、定期実行のどこからつないでも、同じ会話をそのまま続けられます。ターミナルで画像を表示できるようになり、`/rewind` で前のメッセージに戻って書き直したり、そこから別の会話に分けたりできます。料金がかかるツールには1回ごとの費用を設定でき、上限を超えそうになると確認を求めます。

誰に関係する

Hermes Agentを使っている人、とくに複数の画面や複数のパソコンから同じエージェントを使いたい人に関係します。
