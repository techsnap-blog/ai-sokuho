Claude Code v2.1.225：離れた場所のClaude Codeを名前で呼び出して会話開始できるように

30秒でわかる

  • 別のパソコンで動いているClaude Codeを、名前で指定して自分から会話を始められるように（これまでは相手から連絡が来たあとしか返せなかった）
  • 使いすぎを知らせる警告に、上限額・リセット（再開）される時刻・管理者からのメッセージが表示されるように（対応した中継サーバーが必要）
  • 残りは細かい不具合の修正が中心（ログイン用トークンが勝手に短命なものへ差し替わる問題など）

何が変わった

今回いちばん実感しやすいのは、離れた場所で動いているClaude Codeを名前で呼び出して、自分から会話を始められるようになったことです（Remote Control＝別のパソコンやスマホからClaude Codeを遠隔操作する仕組み）。これまでは相手のClaude Codeから連絡が来たあとしか返せませんでしたが、`ListAgents`という一覧に出る名前を指定して、こちらから話しかけられます。あわせて、使いすぎを知らせる警告が上限額・利用枠がリセットされる時刻・管理者からのひとことまで表示するようになりました（対応した中継サーバーが必要）。スマホの「Claude」アプリから貼った写真も、いったんファイルに保存して読み直すのではなく、そのままClaudeに渡るよう改善されています。ほかは不具合の修正が中心で、たとえばログイン用の長期トークンが一時的な通信エラーで短命なものに置き換わり、画面なしの自動実行が止まってしまう問題などが直りました。料金への影響は公式には書かれていません。

誰に関係する

複数のパソコンやスマホからClaude Codeを遠隔で使い分けている人、チームや会社で利用枠の上限を決めて運用している人に関係します。1台だけで使っている個人にとっては、今回は主に不具合の修正が恩恵になります。
