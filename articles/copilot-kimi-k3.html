GitHub CopilotでKimi K3が使えるように。安く使えるコーディング向けAIモデルが選択肢に追加

30秒でわかる

  • GitHub Copilot（コード作成を手伝うAI）で、新しいAIモデル「Kimi K3」が選べるようになった（お試しではなく正式提供）
  • Kimi K3はコーディングが得意で、しかも料金が安いのが売り。中身が公開されている「オープンな」モデル
  • VS Code・Visual Studio・スマホのGitHubアプリ・JetBrainsなど、幅広い環境で使える

何が変わった

GitHub Copilotに、使うAIモデルとしてKimi K3が正式に追加されました。モデルとは「実際に文章やコードを考えるAIの頭脳」の部分で、Copilotではこれを目的に合わせて切り替えられます。Kimi K3は中身（重み）が公開されている「オープンウェイト」モデルで、コード関連の作業（エージェント的な自動作業）が得意なうえ料金が安いとされています。対応する環境は幅広く、VS Code、Visual Studio、Copilot CLI（コマンドで使うCopilot）、クラウド上で動くCopilotエージェント、GitHubのアプリやサイト、スマホのGitHub Mobile、JetBrains、Xcode、Eclipseで順次使えるようになります。料金は使った分だけの従量課金で、入力100万トークンあたり3ドル、出力100万トークンあたり15ドル（トークン＝AIが読み書きする文字のかたまり）。なお会社向けのCopilot BusinessとEnterpriseでは初期状態はオフで、管理者が設定でこのモデルを許可して初めて使えます。

誰に関係する

Copilotを使っていて、コード作業を安いモデルで試したい人に関係します。個人向けのPro・Pro+・Maxのほか、会社で使うBusiness・Enterpriseが対象です。会社で使う場合は、管理者がKimi K3を許可しないと選べない点に注意（オープンなモデルなので、GitHubは会社のセキュリティ方針に照らして確認してから有効にするよう案内しています）。
