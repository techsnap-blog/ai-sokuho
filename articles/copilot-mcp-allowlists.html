GitHub Copilotrelease2026-08-06

GitHub Copilotで、会社が使えるMCP連携先を一括管理。危険な接続先はまとめてブロック

30秒でわかる

  • 会社の管理者が、Copilotで使えるMCP接続先を一括で許可/拒否できるように
  • MCP＝AIが外部ツールやデータとやり取りする仕組み。信頼できない接続先はまとめてブロック
  • Copilotアプリ・CLI・VS Codeで正式提供

何が変わった

GitHub Copilotの企業向け管理設定に、MCPの許可リストが正式に加わりました。MCP（AIが外部のツールやデータとつながる仕組み）について、会社の管理者が「使ってよい接続先」と「使わせない接続先」を全社でまとめて指定できます。設定ファイルにallowedMcpServers（許可）とdeniedMcpServers（拒否）を書き、接続先のURL・コマンド・名前で指定でき、まとめ指定(ワイルドカード)にも対応します。狙いは、開発者が必要とする接続先は承認しつつ、危険・非準拠な接続先は全社で遮断して安全を保つこと。Copilotアプリ・Copilot CLI・VS Codeで利用できます。

誰に関係する

会社でCopilotを導入する管理者・情報システム担当に関係します（上級者向け）。社員が使う外部連携を一元管理して、安全に運用できます。
