OpenAI Codex CLI 0.149.0：起動中のAI作業を一覧で管理する「エージェント・ダッシュボード」を追加

30秒でわかる

  • 動いているAIの作業を一覧で管理できる「エージェント・ダッシュボード」（`codex agents`）を追加。検索・開始・開く・名前変更・停止をその画面から操作できる（ショートカットも設定可）
  • 作業フォルダを会話の途中で切り替えられる `/cd`・`/pwd`・`/cwd` を追加。今どこで作業しているかも確認できる
  • 既存のセッション（動作中/リモート）に後からメッセージを送る `codex queue`、不調の原因を自動診断する `codex doctor` の強化なども

何が変わった

今回の目玉は、動いているAIの作業（タスク）を一覧画面でまとめて扱える「エージェント・ダッシュボード」です。`codex agents` と打つと、いま走っている作業を検索して、新しく始めたり、開いたり、名前を変えたり、止めたりを1画面からできます（よく使う操作にショートカットも割り当て可能）。複数の作業を並行させると「どれが何だっけ」となりがちですが、それを整理できるイメージです。あわせて、会話の途中で作業フォルダを移動できる `/cd`、今の場所を確認する `/pwd`・`/cwd` を追加。すでに動いているセッションに後からメッセージを積んで送る `codex queue`、テキスト編集のVim操作の拡充（`cw`・`c$`・`cc` など）も入りました。不調時に原因を探す `codex doctor` は、セキュリティソフトによる遮断・ネットワークやプロキシの失敗・アプリの状態・更新の接続まで見てくれるようになっています。ほかは不具合の修正が中心で、通信が切れたあとの再接続、Windowsの画面履歴の保持などが直りました。料金への影響は公式には書かれていません。

誰に関係する

Codex（コーディングを手伝うCLI＝コマンドで操作するツール）を使う人に関係します。とくに複数のAI作業を同時に走らせて管理しづらかった人、作業フォルダをよく移動する人、接続トラブルの原因が分からず困っていた人にうれしい更新です。
