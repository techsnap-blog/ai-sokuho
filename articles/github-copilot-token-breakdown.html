GitHub Copilotupdate2026-08-11

GitHub Copilotの利用明細に「モデル別トークン内訳」が追加。何にいくらかかったか追えるように

30秒でわかる

  • GitHub Copilotの使用量レポートに「モデル別トークン内訳」が追加された
  • モデルごとに、入力・出力・キャッシュ読み書きのトークン数とAIクレジット消費を突き合わせられる
  • どのモデルに何のトークンでいくらかかったかを明細で説明できる

何が変わった

GitHub Copilotの利用明細（AI usage report）が、これまでは「AIクレジット（利用量に応じて減る社内ポイントのようなもの）」の合計しか出ず、内訳が分かりにくいものでした。今回の更新で、使ったAIモデルごとに、入力トークン・出力トークン・キャッシュの読み書きトークンが、消費したAIクレジットと並べて表示されるようになりました。「トークン」はAIが文章やコードを処理するときの文字のかたまりの単位で、これが多いほど費用がかさみます。明細は課金設定のAI利用ページからダウンロードできます。

誰に関係する

GitHub Copilotを有料で使っている個人、チームや会社の管理者に関係します。管理対象は、Copilot for Individualsの全ユーザーと、Copilot Business／Enterpriseの管理者です。「今月なぜこの金額なのか」を、どのモデルのどのトークンで増えたかまで説明できるようになります。
