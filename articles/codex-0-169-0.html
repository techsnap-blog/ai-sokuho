OpenAI Codex CLI 0.169.0：横の相談チャットをタブで複数開けるように。過去の作業も検索できる

30秒でわかる

  • 希望者向けのターミナル画面で、サイドチャットをタブで複数開き、キーボードやマウスで切り替えられる。保存したタブは再起動後も開き直せる
  • エージェントの管理画面で、過去の作業を名前・指示の冒頭・作業フォルダで検索できる
  • 画面いっぱいの会話記録で、終わった作業の細部をたたんで答えだけを見られる

何が変わった

Codex（コーディングを手伝うCLI＝コマンドで操作するツール）の0.169.0が公開されました。希望者が自分で有効にするターミナル画面で、サイドチャット（本題の作業とは別に質問できる横の会話）をタブで複数開けるようになりました。キーボードでもマウスでも切り替えられ、手元に保存したサイドチャットは再起動したあとでも開き直せます。 複数のエージェントをまとめて見る管理画面では、昔の作業を、名前・指示の冒頭・作業していたフォルダで検索できます。会話記録を全画面で見るときは「Collapse turn details」を選ぶと、終わった作業の細かい記録がたたまれます。答えは表示されたまま残り、ツールの出力も検索できます。 ほかに、自分で用意したモデルの接続先をターミナルから追加・編集できるようになりました。修正面では、計画を承認して「会話をリセットして実装」を選んだとき、承認した計画の全文が新しい会話に渡るようになっています。Windowsでの一部のパス処理の不具合も直りました。

誰に関係する

Codexを使っている人に関係します。1つの作業を進めながら、横で別の質問もしたい人には便利な更新です。
