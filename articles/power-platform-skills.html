Claude Code・Copilotで業務アプリ開発を助けるプラグイン集「Power Platform Skills」（Microsoft公式）

30秒でわかる

  • Claude Code・GitHub Copilotに、Microsoftの業務アプリ基盤「Power Platform」の開発スキルを足すプラグイン集（Microsoft公式）
  • Power Pages（Webサイト作成）・Power Automate（作業の自動化）・Canvas Apps など8種類をカバー。AIに「こんなアプリを作って」と頼む土台になる
  • インストーラーでまとめて導入でき、自動更新にも対応。無料・オープンソース（MITライセンス）（GitHub ↗）

何が変わった

Power Platform Skillsは、AIコーディングツール（Claude Code / GitHub Copilot）に、Microsoftの「Power Platform」を開発するための機能を追加するプラグイン集です。Power Platformは、コードをあまり書かずに業務用のアプリや自動化を作れるMicrosoftのサービス群（ざっくり言うと、社内の申請フォームや自動処理などを手早く作る道具）です。このプラグイン集には、Power Pages（React等でサイトを作る）／モデル駆動アプリ／Power Automate（クラウドの自動処理を作る・直す）／Canvas Apps など8種類が入っており、AIに指示してこれらを作らせる土台になります。導入はWindows/Mac/Linux対応のインストーラーが、使えるツールを検出してプラグインの登録・導入・自動更新まで行います。

誰に関係する

Power Platformで社内アプリや自動化を作る人、これから触る開発者に向いています。Claude Code か GitHub Copilot のどちらでも使え、スクリプト1本のインストーラーでまとめて入れられます。ローカルで試す開発モードや、テレメトリ（利用データ送信）の停止も用意されています。
