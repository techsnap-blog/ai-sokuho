Claude CodeやCursorに134種類の開発スキルをまとめて足せる無料プラグイン「Vibes Plug」

30秒でわかる

  • Claude Code・Cursor・Antigravityに、134種類以上の開発スキルをまとめて追加できる無料プラグイン（スキル＝AIに持たせる専門ノウハウ集）
  • フロントエンド・バックエンド・データベース・テスト・UI設計など9分野を1つでカバー
  • 誰でも無料で使えるMITライセンス。git・npm・インストーラなど複数の入れ方に対応

何が変わった

Claude CodeやCursorのようなAIコーディングツール（コードを書く作業をAIに手伝わせるアプリ）は、あらかじめ「スキル」を読み込ませておくと、その分野の作法に沿った提案をしてくれます。Vibes Plug ↗は、この開発向けスキルを134種類以上まとめて一括で追加できる無料プラグインです。中身は、フロントエンド・モバイル（27種）、バックエンドや各言語（21種）、SaaS・クラウド構成（20種）、テストとセキュリティ（19種）、UI/UX設計（12種）、AI連携（12種）、データベース（7種）など9つの分野に整理されています。対応するのはAnthropicのClaude Code ↗とClaude Desktop、Cursor、Antigravityの3系統で、それぞれの設定ファイル（`CLAUDE.md`や`.cursorrules`など）を通して読み込ませます。React 19やNext.js 15など2026年時点の新しい構成を前提に作られています。

誰に関係する

Claude CodeやCursorをすでに使っていて、扱う分野ごとに設定を用意するのが面倒な人に向いています。導入にはgit・npm・付属のインストーラのいずれかが使え、ライセンスはMIT（無料で改変・再配布も可）です。個人が公開しているプラグインなので、業務で使う場合は中身を確認したうえで取り入れるのがよいでしょう。
