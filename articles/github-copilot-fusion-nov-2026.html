GitHub Copilotupdate2026-11-18

GitHub Copilot Fusionがgithub.comとVisual Studioでも使えるように。使われるモデルも入れ替え

30秒でわかる

  • Copilot Fusionは、モデル選択欄で選ぶと、作業ごとに合うモデルをCopilotが選んで組み合わせる仕組み。使う側は「頑張り度合い」を決めるだけ
  • github.comの最新版、Visual Studio、GitHub Mobileのベータ版（iOS・Android）で使えるようになった
  • GitHubの発表では、最上位のFusion MaxがTerminal-Bench 4.1で71.2%を記録

何が変わった

Copilot Fusion ↗は、Copilotのモデル選択欄に並ぶ選択肢の1つです。選ぶと、Copilotが作業ごとにモデルを選び、組み合わせて進めます。使う側が決めるのは、どこまで手間をかけるかの段階だけです。 11月17日の更新で、github.comの最新版、Visual Studio、GitHub Mobileのベータ版アプリ（iOS・Android）でもFusionを選べるようになりました。通常版のスマホアプリにも近く対応する予定です。中で使われるモデルも足され、Fusion MaxにClaude Sonnet 5.5、Fusion HighにGPT-6.1 Terra、Fusion StandardにMAI-Code-2が入りました。 GitHubによると、Fusion Maxはターミナル操作の課題を解かせるベンチマーク「Terminal-Bench 4.1」で71.2%を解きました。Opus 5.5とFable 5.2より5.4ポイント高く、費用はFable 5.2より88%、Opus 5.5より57%少ないとしています。
