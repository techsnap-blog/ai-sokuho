AIが読むコマンド結果を縮めてトークンを節約する「rtk」。Claude Codeに自動で組み込める

30秒でわかる

  • rtk ↗は、コマンドの結果を短くまとめてからAIに渡すことで、AIが読む量を最大90%減らすツール
  • gitやテスト、ビルドなど100種類以上のコマンドに対応。例として、15行あるgit pushの結果が「ok main」の1行になる
  • Claude Codeに組み込むと、AIが打つコマンドを自動でrtk版に置き換える。Windows・Mac・Linuxで動く

何が変わった

AIのコーディング道具は、コマンドを実行するたびに結果の文章をすべて読み込みます。テストやgitの結果には決まり文句や同じ行の繰り返しが多く、そのぶんトークン（処理した文字の量）を使います。rtkは、不要な行を削る、似た行をまとめる、繰り返しを件数にまとめるといった処理をして、短くした結果だけをAIに渡します。たとえばテストが失敗したとき、200行を超える結果を約20行にまとめ、失敗した箇所だけを残します。「rtk init -g」で設定すると、Claude Codeが「git status」と打ったときに自動で「rtk git status」へ置き換わるので、AIにrtkの使い方を覚えさせる必要はありません。この置き換えはBashでのコマンド実行にだけかかります。Claude Code標準のファイル読み込み（Read）や検索（Grep・Glob）は対象外です。なお、減るのはコマンド結果の量で、料金がその割合で下がるわけではないとREADMEは注意しています。

誰に関係する

Claude Codeなどで、gitやテストのコマンドをAIにたくさん実行させている人に向いています。WindowsではPowerShellで「winget install rtk-ai.rtk」と打てば入ります。名前が同じ別のソフトがあるので、Rustの道具（cargo）で入れる場合はREADMEの手順に従ってください。
