GitHub Copilotupdate2026-10-14

JetBrains版GitHub Copilotが更新。エラー表示から「Fix」で直せるように、MCPの自動起動も止められる

30秒でわかる

  • コードのエラー表示から「Fix」を選ぶと、Copilotがその場で修正してくれるようになった
  • MCPサーバーの自動起動を止める設定が追加。外部ツールをいつ使い始めるかを自分で決められる
  • JetBrains IDE 2025.1のサポートは終了。使い続けるには2025.2以降への更新が必要

何が変わった

IntelliJ IDEAやPyCharmなど、JetBrains製の開発ソフト（IDE）で使うGitHub Copilotが更新されました。コードのエラーや警告に出る修正候補のメニューに「Fix」が加わり、選ぶとチャット欄が開いてCopilotが修正を始めます。使える環境ではエージェントモード（AIが自分でファイルを書き換えるモード）で動き、使えない場合は質問に答えるモードに切り替わります。MCPサーバー（AIが外部ツールとやり取りする仕組み）については、CopilotとClaudeで自動起動を止める設定が入りました。企業の管理者は、新しい会話で最初に使うモデルを指定できます。利用者はモデル選択欄から別のモデルを選べます。このほか、会話を1往復ずつまとめて移動できる表示、自分のメッセージのコピーと編集、アカウント切り替えの追加など、チャット画面も使いやすくなっています。

誰に関係する

JetBrains製の開発ソフトでCopilotを使っている人に関係します。2025.1を使っている場合は、先にIDEを2025.2以降へ更新する必要があります。
