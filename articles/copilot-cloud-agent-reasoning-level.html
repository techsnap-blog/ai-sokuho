GitHub Copilotの自動作業AIに「考える深さ」設定。難問には深く、ただし料金は増える

30秒でわかる

  • 自動で作業するCopilotに「どれだけ深く考えてから答えるか」を設定できるように
  • 難しい問題では答えの質が上がる
  • ただし深くするほど消費トークン(＝クレジット＝料金)が増える

何が変わった

GitHub Copilotのクラウド上で自動的に作業を進めるAI(cloud agent)に、「考える深さ(reasoning level)」を設定できるようになりました（対応モデルのみ）。これは答えを出す前に、AIがどれだけじっくり考えるかを決めるもので、深くするほど複雑な問題への答えが良くなる一方、使うトークンが増え、その分クレジット(料金)も多くかかります。使うときは、モデルを選ぶのと一緒に考える深さを選び、その設定が作業中ずっと適用されます。対象は、クラウドエージェントを使えるPro・Pro+・Business・Enterprise・Maxの各プランです。

誰に関係する

Copilotに自動で作業を任せる開発者に関係します。簡単な作業は浅く安く、難しい作業は深く、と品質と料金のバランスを自分で選べます。
