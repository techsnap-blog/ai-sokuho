何が変わった

Claude-Code-History-VSCode ↗は、AIコーディングツール（AIに指示してコードを書かせる道具）との会話履歴を、コード編集アプリ「VS Code」の中から見返せる無料の拡張機能です。ふだんターミナル（黒い画面でコマンドを打つ操作）で使うAIとのやり取りは後から探しにくいですが、この拡張を入れると、Claude Code・Codex・OpenCode・Grok・GitHub Copilot の5つのツールの履歴を、プロジェクトごとにまとめて一覧できます。ざっくり言うと、「いつ・どのAIに・何を頼んで・どう直されたか」を後から検索して追えるようになります。主な機能は、何千件もの過去のやり取りを対象にした全文検索、AIが加えたコードの変更を色分けで見せる差分表示、そして使ったトークン量・費用・編集回数を示すチャートや週次まとめです。会話をMarkdown形式で書き出す機能もあります。基本的な閲覧や直近の履歴は無料で使え、履歴を無制限に見たい場合などは有料のPro機能が用意されています。

誰に関係する

Claude CodeやCodexなどのAIツールで日常的にコードを書いている人に関係します。過去にAIへ出した指示や、AIが加えた修正を後から探して確認したいときに役立ちます。複数のAIツールを併用している人ほど、履歴を一箇所でまとめて見られる利点が大きいでしょう。
