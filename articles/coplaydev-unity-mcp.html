Unityの操作をAIに頼める「MCP for Unity」。シーン作りやスクリプト編集を文章で指示

30秒でわかる

  • MCP for Unity ↗は、AIとUnity（ゲームやアプリを作る開発ソフト）をつなぐツール
  • シーンやオブジェクトの作成、スクリプトの編集、素材の管理、テスト、ビルドを文章で頼める
  • Claude Desktop、Claude Code、Cursor、VS Code、Gemini CLIなど、MCPに対応したAIツールで使える

何が変わった

MCP for Unityは、MCP（AIが外部ツールとやり取りする仕組み）を使って、AIアシスタントとUnityエディタをつなぎます。AIに文章で頼むと、AIがUnityを操作してシーンやゲームオブジェクト（画面に置く部品）を作ったり、C#のスクリプトを書き換えたりします。素材の管理、テストの実行、処理の重さの計測、ビルドまで、50の操作が用意されています。対応するのはUnity 2021.3 LTSから6.x系までで、Python 3.10以上（`uv` 経由）が必要です。最新版は10月4日公開のv10.3.0です。
